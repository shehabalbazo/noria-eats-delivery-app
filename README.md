# 🍔 Food Delivery App with AI Chatbot

A modern food delivery application built with Flutter, featuring an AI-powered chatbot that enhances the user experience through intelligent food recommendations, multilingual support, and smart assistance.

## 🚀 Features

- 🍽️ Food recommendation system based on user preferences
- 🤖 AI chatbot powered by Firebase Functions and Hugging Face
- 🌍 Multilingual conversation support
- 🛒 Easy food ordering and cart management
- 🎟️ Coupon and discount integration
- 🧭 Smart navigation assistant for helping users explore the app
- 🔥 Real-time data synchronization with Firebase

## 🛠️ Technologies Used

- **Flutter** – Cross-platform mobile application development
- **Firebase**
  - Authentication
  - Cloud Firestore
  - Cloud Functions
  - Cloud Storage
- **Hugging Face API** – Natural Language Processing and chatbot intelligence
- **Dart** – Application programming language

## 📱 AI Chatbot Capabilities

- Understands user requests in multiple languages
- Suggests meals and restaurants
- Recommends available coupons and discounts
- Answers user questions about orders and products
- Provides a more personalized ordering experience

## 🎯 Project Goal

The aim of this project is to combine food delivery services with artificial intelligence to create a smarter, more interactive, and user-friendly ordering experience.

## 👨‍💻 Developed With

Flutter • Firebase • Hugging Face API
